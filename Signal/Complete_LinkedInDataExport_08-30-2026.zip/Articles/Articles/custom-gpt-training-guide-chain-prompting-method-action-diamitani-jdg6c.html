Custom GPT Training Guide - Chain Prompting Method (With Action Schemas)

Created on 2025-05-04 07:31

Overview

This training guides you through the complete process of building a Custom GPT using ChatGPT’s Custom GPT Builder combined with the Chain Prompting Method. 

Chain Prompting, as used in this training, is a structured workflow that starts by defining your assistant’s purpose, then uses a series of specialized GPTs (Instruction Architect, Knowledge Base Architect, Funky) to generate system instructions, knowledge files, and action schemas. 

Each output feeds into the next, allowing you to create fully customized GPTs step by step - from idea to deployed assistant using repeatable, modular prompts.

By the end, you’ll have a fully functional, personalized AI assistant ready for any project and the option to publish it to the GPT Store.

What is a Custom GPT?

A Custom GPT is a personalized AI assistant you can create using ChatGPT, allowing you to control how it behaves, what it knows, and what tasks it can perform.

Accessing the Custom GPT Builder:

  • Subscribe to ChatGPT Plus ($20/month).

  • Click the circle with your name (top right in ChatGPT).

  • Select "My GPTs."

  • Click "Create GPT."

Link: chatgpt.com/gpts/editor

Configurations Breakdown

When setting up your Custom GPT, you’ll fill out these fields:

Name

  • What to enter: The name of your Assistant.

  • Purpose: This is how users will recognize your GPT.

Description

  • What to enter: A short summary of what your GPT will do.

  • Purpose: Explains the general function of your GPT to users.

System Instructions

  • What to enter: How your GPT should act - tone, personality, tasks, and any rules.

  • Purpose: Controls how the GPT responds and behaves.

Knowledge Base

  • What to enter: Files or documents you want the GPT to use for extra knowledge.

  • Purpose: Helps your GPT understand specific topics or industries beyond its default data.

Conversation Starters

  • What to enter: Example questions or prompts for users to try.

  • Purpose: Gives users ideas on how to interact with your GPT.

Capabilities

  • Browsing: Lets GPT search the internet.

  • Code Interpreter: Allows GPT to run code and handle data.

  • DALL·E: Lets GPT generate images.

  • File Search: Upload documents the GPT can search and reference during chats.

  • Canvas: Split-screen interface for productivity tasks.

Action Schemas (Advanced/Optional)

Action schemas are structured commands that let GPT trigger actions using APIs or webhooks.

  • Examples: Login to Gmail and send email, Upload a file to Google Drive Make a log entry in a CRM.

  • Purpose: Lets GPT perform external tasks by connecting to real-world apps or services (requires scripting and hosting backend functions).

Step 1: Create System Instructions — Instruction Architect

This step helps you write the System Instructions that tell your GPT how to behave, what tone to use, what type of users it’s helping, and any rules or workflows it should follow. You can either write the instructions yourself or use the Instruction Architect tool to automatically generate them by providing a simple prompt describing what you want your GPT to do. The output will be a full set of instructions that you’ll paste into the GPT Build

  • Tool: Instruction Architect

  • Prompt: "Please use the following prompt to generate system instructions for my assistant: (your prompt/idea)."

  • Output: Full System Instructions (personality, tone, workflow, compliance rules).

Step 2: Define Functions (Optional) — Funky

This step lets you create Function Schemas, which allow your GPT to perform advanced tasks like sending emails, searching databases, or calling APIs. You can write the schemas manually or use the Funky (Function Schema Builder) tool to generate them automatically based on your System Instructions. 

If this is too complicated, or unnecessary, just skip this part. For more details on how to fully create action schemas and deploy them, follow our instructions at the end of this guide. Even without actions, your custom GPTs can still be very powerful.

  • Tool: Funky (Function Schema Builder)

  • Prompt: "Please use the following system instructions to generate OpenAI function schemas for this assistant."

  • Output: A Function Schema in JSON format (defines expected inputs/outputs for your GPT).

*Important:

  • Function Schemas only define the actions your GPT can call.

  • You must also create and host the actual backend function (the code that does the work) on a platform like Vercel, Netlify, Replit, or your own server.

  • Once hosted, you'll provide the HTTPS endpoint (URL) in the GPT Builder when setting up Actions.

Step 3: Build Knowledge Base — Knowledge Base Architect

This step helps you gather and organize important reference information that your GPT will use to answer questions or provide expert guidance. The Knowledge Base Architect can automatically compile verified, recent information into a format that can be uploaded into GPT Builder.

  • Tool: Knowledge Base Architect

  • Prompt: "Please use the following data to create a verified Knowledge Base from trusted, recent sources: (paste system instructions and action schema if necessary).”

  • Output: A table of resources (Markdown or table format) with links to trusted, recent sources.

You can:

  • Download the table and upload it to your Custom GPT as a Knowledge File.

  • If a link points to a PDF, download and upload the PDF file directly.

  • If a link points to a website, open the page, right-click, select Print, and save it as a PDF. Then upload the PDF to your Custom GPT.

  • Alternatively, link to the live table or web pages inside your GPT’s instructions if you prefer to keep resources online.

How It Works:

  • You provide your GPT’s System Instructions and (optional) Function Schema.

  • The Knowledge Base Architect generates a table of trusted, relevant sources.

  • You download/save each source as a PDF or collect the table itself.

  • You upload the files directly into GPT Builder Knowledge section

Important:

  • If you don’t provide a Knowledge Base, your GPT will only use its default training data.

  • A good Knowledge Base makes your GPT much more reliable for specific topics or industries.

  • Update your Knowledge Base regularly to keep the content fresh.

Closing

And that's all, folks! Once your GPT is fully configured, you can test it, make adjustments, and publish it for private use or share it publicly in the GPT Store.

Example Function Template + Hosting Guide

Use this to connect your GPT’s Function Schema to a working backend function.

Example: Simple "Say Hello" Function (Node.js)

javascript

// hello.js

export default function handler(req, res) {

    const name = req.query.name || "there";

    res.status(200).json({ message: Hello, $​{name}! });

}

How to Host this Function on Vercel

  1. Create a free account at vercel.com.

  2. Install the Vercel CLI (optional for advanced users).

  3. Create a folder on your computer.

  4. Inside that folder, create an api folder.

  5. Place your function in api/hello.js. Your structure should look like:

javascript

my-function/

├── api/

│   └── hello.js

  1. Go to your terminal and run:

bash

vercel

  1. Vercel will upload your function and give you a public URL like:

arduino

https://my-function.vercel.app/api/hello

  1. Use this URL in your GPT Builder Actions setup.

Example Function Schema (for GPT Builder)

json

{

  "name": "say_hello",

  "description": "Greets the user by name.",

  "parameters": {

    "type": "object",

    "properties": {

      "name": {

        "type": "string",

        "description": "The name of the person to greet"

      }

    },

    "required": ["name"]

  }

}

  • Paste this in GPT Builder when adding an Action.

  • Link it to your Vercel function’s URL.
