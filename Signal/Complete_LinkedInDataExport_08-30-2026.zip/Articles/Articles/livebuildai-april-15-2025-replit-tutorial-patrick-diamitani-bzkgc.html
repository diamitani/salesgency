How to build a front end user interface for a custom assistant.

In this tutorial, I'll guide you through the process of creating a front end application for your custom assistant, using openai assistants API, chat GPT custom GPTs and replit.com. The goal is to create a working assistant chatbot that uses Replit for an interface and is powered by OpenAI.

End product

Here's what the end product looks like after doing the build - https://awstutor.replit.app/

Getting Started

The first thing I did was use a process called, "Chain Prompting" to make the most out of my tools. For example, I used a system of Custom GPTs, OpenAIs Assistant API and finally Replit to build the end product. Here's an example of the tools and process I used:

Overview - created a framework for what I was going to build.

Create a standalone openai assistant, using the open ai assistants api and replit as a front end.

Tools:

  • ChatGPT - leveraged Chat GPT custom GPTs to build my assistant structure.

  • OpenAI Assistants API - used Assistants dashboard to set up custom assistant.

  • Replit.com - used Replit to prompt front end development.

1. Highly Suggested Prompts

  • Highly Suggested Prompts - used to prompt my prompt - asked it to help me write a prompt to write a prompt that would generate system instructions. See my exact prompt below:

I want to create a system instructions for a personal tutor to help me with the AWS cloud practioner exam. I have a tool called system instructions architect, and I want to develop a prompt that will help it make the best system instructions.

Here's what it came up with:

2. System Instructions Architect

  • System Instructions Architect - Using the above prompts, I then entered into the System Instructions Architect to further define exactly what I was building. I then asked to create function schemas (actions that the assistant could take) based on the instructions. Here's an example of the prompt and functions below:

You are a personal AWS Cloud Practitioner tutor designed to help a learner master all content required to pass the CLF-C02 certification exam. Your primary objective is to make the user confident and competent across all domains of the exam: Cloud Concepts, Security and Compliance, Cloud Technology and Services, Billing and Pricing, and AWS Support.

3. Open AI Assistant Dashboard

From there, I went to OpenAI and created a new Assistant in the Dashboard. I copy and pasted my system instructions and function schemas and made sure to grab the Assistant ID and Vector Store ID (knowledge base storage) for later to add to Replit.

4. PromptBuilder Architect

  • PromptBuilder Architect - After copy and pasting the above into a google doc to manage my files, I then pasted them into PromptBuilder Architect, a tool built to help build tools on platforms like Lovable, Replit, etc. It breaks down what you're looking to do in prompts so that you can keep your credits intact and not waste time going back and forth with the assistant. Here's an example of the Master Prompt:

Build a full-stack SaaS-level web application called “AWS Course Practitioner Tutor.” Deliver interactive learning for the AWS Cloud Practitioner (CLF-C02) exam via OpenAI Assistant ID, with deep integration of custom functions and vector store.

5. Replit

Finally, I used Replit. In all honesty, I wasn't as patient as I could have been, and instead of just building one version and fixing all edits, I actually ended up with three different versions. 1 was created using the system instructions and project architecture details and just pasting it in (example visual 1 from above), the next was made using the Prompt Builder Architect replies and the final one was built using my natural language prompts to just ask it to build what I wanted. Either way, the end result was a front end, a custom chatbot and a user dashboard. Check them out below!

Lessons learned

The point of this was to show you my process for developing a custom assistant and creating a custom front end, so that anybody could build any tool. What I ended up doing in the process, was learning a lesson in patience and understanding that with everything, multiple edits needed to be done to make sure everything worked correctly. What I thought was going to be a 5-minute tutorial, ended up being an hour long exorcise that honestly still isn't quite finished. But the miracle is, I was able to build and not just talk, in that hour. In one hour, I built what I haven't been able to build in years up til now.

So I guess that's the goal. Find your idea, find your process and build. And hey - you just might have to edit along the way.
