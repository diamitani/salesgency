How to build a personal affirmation tool using eleven labs.

You smart. You loyal. I appreciate you.

But sometimes, we don't always think this way about ourselves. I found a great tool called ElevenLabs, that allows you to create amazing voice audio from text. Here's what I did.

  1. Sign Up - Elevenlabs.io

  2. Choose your character (JK, but select a type of voice project you want)

  3. Generate audio

It's that simple. I wanted to do something interesting, after watching a Youtube ad that got extended due to being too busy to change the channel and hit the skip button. It was Mr. Jim Kwik on the line talking about his journey and it made me think, "it is good to have someone say your dreams out loud." So I figured, if I can't get any of you to do it (hint hint, jk again), might as well create an affirmation for myself.

Now I could have gotten a voice translator to copy my own voice, but I wanted someone else to tell me I was great. So I chose between the various library of voices and found a calm deep assuring voice that'd make me feel good about myself (Barry White anyone?).

The result is in the video below - check it out, it's only 5 seconds! Keep in mind this was a one shot try and you can do a lot more with tweaking, spacing, pauses etc, but just wanted to show you how it works.

If you'd like to do something more in depth, here is a tutorial on how to create an audio book using Eleven Labs.

First, I copy and pasted an online course I had created previously into the "Audio Book" section on the EL dashboard. To create a course, you can simply use a tool like Chat GPT to generate a course based on your topic. You can also check out this Docu2Course platform I built using Lovable. Make sure you ask it to not only create an online course structure based on a topic you prompt it, but also generate the course content for each module.

Once that's done, simply add each chapter in the dashboard tabs and choose a voice. For this example, I chose "Aria" a friendly, yet professional female voice to engage learners.

After I clicked "generate" in the top left corner for each chapter, I then exported the audio using the button on the top right (you can simply select export to generate audio for the whole document, or select chapters).

And that's it! From there you can upload it to a podcasting service for audio only (Eleven Labs provides direct export options as well), or use a multitude of tools to create AI powered video/visuals (I used Descript in the example below): https://youtu.be/67X5Owzi3UI
