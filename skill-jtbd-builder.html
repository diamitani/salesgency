The 6-step JTBD build

Name the job

The progress the customer is trying to make — in their words, not yours.

Map the dimensions

Functional, emotional, and social: all three, because all three drive the hire.

Surface the pain points

Where the current solution fails the job. Specific, quoted, real.

Write the user stories

Stories structured around the job — so acceptance means the job got done.

Derive the value props

Messaging that answers the job, not a feature list.

Feed the build

Stories flow straight into the PRD and the POP artifact package.
