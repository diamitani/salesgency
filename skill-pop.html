The 6-step flow

Detect source + persona

Accepts input via direct prompt, task, or intake form — and adapts to who's asking.

PAL intent recognition

Compiles your ask into a 2–3 sentence Intent Brief. No prompt-engineering required from you.

Intake wizard

Five envisioning questions: Outcome, Working model, Tools, Current knowledge, Knowledge gaps.

RAG DAL gap research

Retrieves what's known, flags what's missing, researches the gaps.

NPAO orchestration

Classifies work N→A→P→O and sequences it on a 4Ds timeline with named P&L ownership.

Generate the artifact package

All 11 artifacts, templated and formatted — then a "context flash" persists state so you can resume anytime.

The 11-artifact output package

  • A · Intent Brief — the compiled 2–3 sentence intent.
  • B · JTBD Document — jobs to be done, all three dimensions.
  • C · KPI & Tracking Framework — what success looks like, measured.
  • D · Architecture Diagram — Mermaid diagrams of the system.
  • E · PRD — product requirements doc, conditional on the project.
  • F · Project Overview Doc — ELT/deck-ready overview.
  • G · Asana Export — tasks and CSV, ready to import.
  • H · Purpose-Built Sub-Skill — a new skill spun from the project itself.
  • I · Project Master Doc — 14 sections, the single source of truth.
  • J · Build Guide — hierarchical guide with "done when" conditions and test-in-every-phase.
  • K · Execution Handoff Script — guardrailed handoff for autonomous execution.
