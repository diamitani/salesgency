The 3-stage pipeline

Build the knowledge base

rfp-kb-builder parses RFP files and HubSpot tickets into atomic Q/A pairs — classified, routed to owners, conflicts flagged, exported as an Excel workbook.

Retrieve with confidence

rfp-answer-retriever runs semantic search against the knowledge base and returns HIGH / MEDIUM / NO MATCH confidence per answer. Batch-processes whole RFPs and auto-creates HubSpot tickets for the gaps.

Draft the response

rfp-response-builder assembles the full response document from knowledge-base answers through a draft generation pipeline.

Close the gaps

Every NO MATCH becomes a ticket, every ticket becomes a new Q/A pair. The knowledge base gets smarter with every RFP.

Reuse forever

Each RFP makes the next one faster. That's the whole game.
