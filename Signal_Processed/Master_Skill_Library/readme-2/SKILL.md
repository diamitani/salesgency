# Figma Sentinel landing page

A single-file, responsive static landing page for the Figma Sentinel Gumloop agent.

## Deploy

1. Create a GitHub repository, for example `figma-sentinel`.
2. Add the provided `index.html` to the repository root.
3. Commit and push.
4. In Vercel, click **Add New → Project**, import the GitHub repository, select **Other** as the framework preset, and deploy.

It also deploys on GitHub Pages from the root of a branch.
