How to Import into n8n in 3 Simple Steps

01. Download JSON

Click any template above to download the unminified, clean `.json` workflow blueprint file.

02. Import to n8n

Open your n8n workspace, click Workflows → Import from File, and upload the downloaded JSON.

03. Attach Credentials

Connect your existing API credentials (HubSpot, Clay, OpenAI, Slack) and toggle Active.
