The 6-phase build

Define the agent's job

One job, stated precisely. Agents that do everything do nothing.

Architect the layers

Persona, role constraints, tool access, and output contracts — each in its own layer.

Write persona and constraints

Voice, boundaries, and refusal behavior, written as instructions not hopes.

Bind tools and handoffs

Which tools, when, and what gets passed onward — the handoff contract.

Install guardrails

No deletes, no secret exposure, confirm-first on the irreversible.

Test against edge cases

Adversarial prompts and weird inputs before the skill ever ships.
