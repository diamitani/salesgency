Free n8n outreach automation templates

The outreach automation backbone of the Salesgency engine, as importable n8n workflows. Feed it a prospect, and it cleans the data, checks your CRM for collisions, enriches the contact, writes PAS-style outreach copy with AI, and routes everything through a human approval step before anything goes out. Free to download, yours to run in-house.

What's inside

01: Trigger Ingest — webhook endpoint that receives prospect payloads
02: Normalizer — cleans and enriches domains, names, and target titles
03: CRM Dedupe Shield — searches your CRM so you never double-prospect
Collision Gate — routes around existing CRM records automatically
04: Contact Reveal & Enrich — contact discovery and enrichment step
05: AI PAS Copywriting — AI agent writes problem-agitate-solve outreach copy
06: Approval Switch — human review via Slack before anything sends

How to install

  1. Download the JSON file (button on this page).
  2. In n8n, go to Workflows → Import from File and select it.
  3. Set your HubSpot access token as the HUBSPOT_ACCESS_TOKEN environment variable (used by the CRM Dedupe Shield).
  4. Connect your AI model credential to the PAS copywriting agent node.
  5. Point your prospect source at the webhook URL and activate the workflow.
