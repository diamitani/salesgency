Key Engineering Principles:
• Zero hardcoded credentials: All API keys stored in .env or n8n credential store.
• CRM Shield mandatory: Checks domain & contact ownership before any outreach action to eliminate deal collisions.
• Human approval gate: High-impact sequences route to Slack with 1-click confirmation buttons.
• Full execution observability: Error retry loops and structured run telemetry for automated self-healing.
