Diagnostic Framework

The 4-Step Automated Triage Protocol.

How our execution engine isolates API rate limits, schema drifts, and credential expiries in real time.

STEP 01

Execution Graph Ingest

Queries the n8n Public API for recent failed executions (/api/v1/executions?status=error) and pulls full run data.

STEP 02

Node Error Parsing

Isolates the exact failing node, HTTP response status (429, 401, 500), missing JSON keys, and unhandled null exceptions.

STEP 03

Root Cause Classification

Categorizes the issue: Credential Expiration, API Rate Throttling, Webhook Payload Schema Drift, or Timeout Overload.

STEP 04

Self-Healing Synthesis

Generates drop-in JSON node replacements with exponential backoff retries, fallback routing, and instant Slack admin alerts.
