Frequently Asked Questions

Everything You Need to Know

How does the agent build workflows?

The agent uses our deterministic compilation AST engine running on Vercel Edge. It transforms your natural language requirements into strict, error-checked n8n workflow JSON, markdown skills, or agent definitions that can be imported immediately into any runtime.

Are my API keys and credentials secure?

Yes. The builder operates with zero secret leakage. All API synthesis happens in isolated ephemeral sandboxes, and production tokens are referenced using secure environment variable bindings (e.g. {{env.KEY}}) rather than hardcoded credentials.

Can I buy individual templates without a subscription?

Yes! Every package in our template store can be purchased individually with a one-time Stripe checkout for lifetime access, source files, and version updates.
