The 6-step PAL build

Parse the intent

Define exactly what the agent must understand — the intent taxonomy it will recognize and act on.

Layer the instructions

Split the stack into system, developer, user, and tool layers with clear precedence rules.

Design the routing logic

Decide how the agent routes between intents, tools, and sub-agents — including handoff contracts.

Write the instruction stacks

Concrete, testable prompts for every layer. No vibes — words that behave.

Set guardrails and fallbacks

What the agent must never do, and exactly what happens when it can't do something.

Emit the PAL blueprint

A documented prompt architecture — the same layer POP compiles before it builds your project package.
